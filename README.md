# the_snake

## Описание проекта

**the_snake** — это классическая игра «Змейка», реализованная на языке
Python с использованием библиотеки [Pygame](https://www.pygame.org/).

Игрок управляет змейкой, которая перемещается по игровому полю и
собирает яблоки. При съедании яблока змейка увеличивается в длине, а
новое яблоко появляется в случайной точке поля. Если змейка сталкивается
сама с собой, игра сбрасывается: змейка возвращается в исходное
состояние (длина 1, случайное направление движения), а поле очищается.
Поле имеет «замкнутые» границы — при выходе за один край экрана змейка
появляется с противоположной стороны.

### Основные возможности

- Управление змейкой с помощью клавиш стрелок (`↑`, `↓`, `←`, `→`).
- Змейка не может развернуться на 180° за один шаг (нельзя мгновенно
  пойти в противоположном направлении).
- Автоматическая генерация яблока в случайной свободной клетке сетки.
- Отрисовка игрового поля, змейки и яблока средствами Pygame.
- Сброс игры при столкновении змейки с собственным телом.

### Структура проекта

- `the_snake.py` — основной файл с логикой игры (классы `GameObject`,
  `Apple`, `Snake` и главный игровой цикл `main`).
- `tests/` — модульные тесты проекта.
- `requirements.txt` — список зависимостей проекта.
- `setup.cfg`, `pytest.ini` — конфигурация линтера и тестового раннера.

### Установка и запуск

1. Клонируйте репозиторий и перейдите в его директорию:

   ```bash
   git clone https://github.com/t-immi/the_snake.git
   cd the_snake
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   source venv/bin/activate  # для Linux/macOS
   venv\Scripts\activate     # для Windows
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите игру:

   ```bash
   python the_snake.py
   ```

### Управление

| Клавиша | Действие              |
|---------|------------------------|
| `↑`     | Движение вверх          |
| `↓`     | Движение вниз           |
| `←`     | Движение влево          |
| `→`     | Движение вправо         |

### Тестирование

Для запуска тестов используйте команду:

```bash
pytest
```

### Технологии
